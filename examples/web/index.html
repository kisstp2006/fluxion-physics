Fluxion Physics, with no threads at all

The same solver as the native demo, compiled to wasm32-freestanding. There is no Io, so there are no workers: each animation frame calls tick(), which runs one fixed step on this thread, and then reads the shapes and joints straight out of wasm memory to draw them.

Drag anything with the pointer. In the yard of joints, ← → drive the car. Bodies that have come to rest fall asleep and turn grey; a step skips them until something disturbs them.
